راهنمای راه‌اندازی سایت با Supabase و GitHub Pages
====================================================

فایل‌ها
-------
- index.html: صفحه اصلی؛ ظاهر، عکس‌ها و موسیقی اصلی حفظ شده‌اند.
- admin.html: پنل مدیریت جداگانه؛ ورود، ویرایش متن‌ها/تاریخ و مدیریت عکس‌ها.
- site.js: بارگذاری تنظیمات و عکس‌های ابری در صفحه اصلی.
- supabase-config.js: آدرس پروژه و کلید عمومی Supabase.
- supabase_setup.sql: جدول‌ها و سیاست‌های امنیتی دیتابیس و Storage.

مرحله ۱ — ساخت پروژه Supabase
-----------------------------
1. به https://supabase.com برو و وارد حساب شو.
2. New project را بزن، نام و رمز قوی دیتابیس انتخاب کن و منطقه نزدیک را انتخاب کن.
3. پس از آماده شدن پروژه، وارد Project Settings > API شو.
4. آدرس Project URL و کلید Publishable (یا anon public key قدیمی) را کپی کن.
5. فایل supabase-config.js را باز کن و این دو مقدار را جایگزین کن:
   https://YOUR_PROJECT_ID.supabase.co
   YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY

مهم: هرگز service_role / secret key را در فایل‌های HTML یا JS نگذار؛ این فایل‌ها عمومی‌اند.

مرحله ۲ — ساخت جدول‌ها و قوانین دسترسی
--------------------------------------
1. در Supabase وارد SQL Editor شو.
2. فایل supabase_setup.sql را باز کن و تمام کد آن را اجرا کن.
3. فعلاً دستور INSERT آخر فایل کامنت است؛ باید پس از ساخت حساب مدیر اجرا شود.

مرحله ۳ — ساخت حساب مدیر امن
----------------------------
1. در Supabase به Authentication > Users برو و Add user را انتخاب کن.
2. ایمیل و رمز قوی بساز. از گزینه‌ای استفاده کن که کاربر تأییدشده ایجاد کند.
3. شناسه UUID همان کاربر را از فهرست Users کپی کن.
4. در SQL Editor این دستور را اجرا کن و UUID واقعی را جایگزین کن:
   insert into public.admin_users (user_id) values ('UUID-کاربر-مدیر');
5. برای سایت عمومی امکان ثبت‌نام آزاد اضافه نشده است؛ تنها کاربری که شناسه‌اش در admin_users باشد مجاز به تغییر محتوا و فایل‌هاست.

مرحله ۴ — بارگذاری در GitHub Pages
----------------------------------
1. این فایل‌ها را در ریشه همان repository قرار بده:
   index.html, admin.html, site.js, supabase-config.js
2. فایل supabase_setup.sql و README.txt برای راه‌اندازی هستند؛ لازم نیست برای اجرا در وب منتشر شوند.
3. Commit و Push کن. GitHub Pages هر دو آدرس را منتشر می‌کند:
   https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
   https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/admin.html

مرحله ۵ — تست
-------------
1. صفحه اصلی را باز کن؛ وضعیت اتصال در زیر گالری عکس نمایش داده می‌شود.
2. از لینک «پنل مدیریت» وارد admin.html شو.
3. با ایمیل و رمز مدیر وارد شو.
4. یک متن را تغییر بده و ذخیره کن؛ سپس صفحه اصلی را تازه‌سازی کن.
5. یک عکس بارگذاری کن؛ باید در صفحه اصلی برای همه بازدیدکنندگان دیده شود.

نکات امنیتی
-----------
- کلید عمومی Supabase در وب‌سایت عمومی قابل مشاهده است؛ امنیت با RLS و سیاست‌های Storage تأمین می‌شود.
- هیچ‌وقت service_role key یا رمز دیتابیس را در فایل‌ها قرار نده.
- اگر مدیر دیگری خواستی، ابتدا حسابش را در Authentication > Users بساز و سپس UUID او را در admin_users ثبت کن.
- عکس‌ها از bucket عمومی gallery ارائه می‌شوند تا بازدیدکنندگان بدون ورود بتوانند آن‌ها را ببینند؛ اما بارگذاری/ویرایش/حذف فقط برای مدیر مجاز است.
- برای حذف یک عکس از پنل، فایل Storage و رکورد آن در جدول gallery_photos حذف می‌شود.
- در صورت بروز خطای CORS، در Supabase تنظیمات URL Configuration را بررسی کن و دامنه GitHub Pages را به Redirect URLs اضافه کن.
